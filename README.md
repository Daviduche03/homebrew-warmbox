# homebrew-warmbox

Homebrew tap for [warmbox](https://github.com/Daviduche03/warmbox) — self-hosted
GUI desktop microVMs.

```sh
brew install --cask Daviduche03/warmbox/warmbox
```

`Casks/warmbox.rb` is generated by GoReleaser on each release. Don't edit it by
hand; the next release overwrites it.
